# Esercizio 4 — Le varianti di Markdown a confronto

## Tabella comparativa

| Costrutto | Markdown originale | CommonMark | GitHub Flavored Markdown |
| :--- | :---: | :---: | :---: |
| Blocchi di codice recintati | Supportati con tripli backticks | Supportati con tripli backticks | Supportati, con evidenziazione automatica del linguaggio |
| Tabelle | Non standardizzate | Supportate in modo limitato | Supportate in modo completo |
| Caselle di spunta | Non native | Non native | Supportate nativamente |
| Testo barrato | Non previsto | Non previsto | Supportato con `~~testo~~` |
| Collegamenti automatici | Non automatici | Non automatici | Supportati automaticamente per URL |
| Note a piè di pagina | Non standard | Non standard | Non supportate nativamente in GitHub |
